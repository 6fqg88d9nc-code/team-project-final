# Командалық жоба: суперқаһармандар галереясы

`index.html` — жобаның басты беті. Онда тоғыз кейіпкердің галереясы және зертханалық жұмыс № 7 аясында диктатор мен қатысушының міндеттері берілген. Бұл репозиторийде әзірге басқа қатысушыларға тиесілі жеке HTML беттері жоқ; міндеттерге сілтемелер басты беттің ішкі бөлімдеріне апарады.

## Рөлдер бойынша орындалған жұмыс

- **Қатысушы:** тоғыз суперқаһарманның HTML карточкаларын құрастырды, CSS-пен галереяны безендірді және JavaScript арқылы таңдау батырмаларын қосты.
- **Диктатор / топ жетекшісі:** Pull Request-тегі кодты қарап, HTML құрылымы мен атауларды тексереді, пікір не түзету сұрауын береді, мақұлданған өзгерісті негізгі тармаққа біріктіреді және қолданылған тармақты жояды.
- **Осы зертханалық толықтыру:** басты бетке команда міндеттері туралы бөлім мен ішкі навигация қосылды.

## Git арқылы жұмыс реті

```bash
git checkout main
git pull origin main
git checkout -b feature-update
git status
git add index.html style.css README.md
git commit -m "Команда міндеттері бөлімін қосты"
git push origin feature-update
```

Содан кейін GitHub-та `feature-update` тармағынан `main` тармағына Pull Request ашып, кодты тексеруге жіберіңіз. Бұл репозиторийде `upstream` remote бапталмаған, сондықтан негізгі репозиторий ретінде `origin` қолданылады.
